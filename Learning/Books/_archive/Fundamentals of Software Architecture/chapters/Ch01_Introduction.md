Software Architecture 的四个维度是什么？::Structure（结构）、Architecture Characteristics（架构特性）、Architecture Decisions（架构决策）、Design Principles（设计原则）
Architecture Decision 和 Design Principle 的区别？::Decision 是必须遵守的规则（如"微服务间只能通过 REST 通信"），Principle 是指导方针（如"优先使用异步通信提高性能"）
Software Architecture 第一定律::Everything in software architecture is a trade-off.
Software Architecture 第二定律::Why is more important than how.
