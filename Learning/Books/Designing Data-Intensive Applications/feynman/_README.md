# feynman/

Feynman check result logs for DDIA chapters.

Each file records what the human explained well (✅) and where gaps remain (⚠️).
Multiple sessions for the same chapter are appended by date to track gap closure.

## AI permission boundary

- **Write structured ✅/⚠️ outcome logs**: ✅ (factual record of sparring results)
- **Write prose or summaries**: ❌
