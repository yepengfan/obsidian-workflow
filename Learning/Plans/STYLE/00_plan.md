# 穿搭 Skill-Tree｜简约高智感 · 通勤工作 · 布里斯班

> 方向：quiet minimalism（靠版型 / 面料 / 克制配色说话，不靠颜色或 logo）
> 原则：少而精、可互搭、把钱花在能复利的地基（合身 + 面料 + 中性色盘）
> 框架对齐：穿搭 = **Skill investment**，不是消费。见 [[Investment-vs-Spending-Framework]]

---

## 系统设定

- **美学**：简约高智感 — tonal dressing + 干净廓形 + 优质面料
- **场景**：全覆盖（通勤工作 / 社交约会 / 日常出行）
- **气候约束**：布里斯班亚热带 — 需要「暖气候版极简」
- **投资原则**：买地基（合身、面料、色盘），不买潮流单品

## 配色盘

- **基础中性（约 90%）**：海军蓝 navy / 炭灰 charcoal / 浅灰 grey / 米白 ecru / 黑
- **柔和点缀（约 10%）**：橄榄 olive / 石色 stone / 燕麦 oatmeal
- **核心手法**：同色系叠加 + 质感对比（tonal dressing）= "高智感"的视觉密码

---

## 面料优先级（布里斯班版）

- **热季（10-3 月）**：亚麻 linen、棉、Tencel/天丝、tropical wool、open-weave 针织
- **凉季（5-8 月）**：细针 merino、轻量羊毛、棉法兰绒
- **避免**：厚重不透气的合成混纺、贴身厚 polo、有衬里的厚西装

## 资源

### 书籍
- 📖 *Dressing the Man* — Alan Flusser（原理圣经：比例/色彩/合身）
- 📖 *True Style* — G. Bruce Boyer（每件单品"为什么这样"，智识密度高）
- 📖 *Ametora* — W. David Marx（日本如何重构美式经典，审美训练）
- 📖 *Gentleman* — Bernhard Roetzel（工具书/参考手册）

### 第一次出手建议（如果只买 3 样）
1. 一条 tropical wool 或好棉的 tailored 长裤（炭灰或海军）
2. 一件细针 merino knit polo（navy 或 ecru）
3. 一双极简皮革小白鞋

> 全部拿去裁缝改到完全合身。这三样能立刻拉高通勤观感，且与后续一切都能搭。
