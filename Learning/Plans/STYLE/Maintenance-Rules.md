# Maintenance Rules 维护规则

> 对抗 [[Investment-vs-Spending-Framework]] §4 Spending Risk 的具体机制。
> 衣橱进入稳态后，靠规则运行，不靠意志力。

---

## 一进一出规则

**买一件新的，必须淘汰一件旧的。** 衣橱总量 ≤30 件。

例外：替换磨损单品不算"新增"（同品类同功能）。

---

## 购物冷静期

1. 看到想买的 → 加入清单，**不当场买**
2. 等 **72 小时**
3. 72 小时后还想要 → 过 [[Capsule-Wardrobe#购物决策框架]] 6 条检查
4. ≥4 条通过 → 买
5. <4 条 → 不买，从清单删除

---

## 冲动购物红旗 🚩

遇到以下念头，立刻停手：

| 念头 | 翻译 |
|------|------|
| "打折好便宜" | 便宜不等于需要 |
| "以后可能穿到" | 没有具体场景 = 不需要 |
| "这个牌子很好" | 品牌 ≠ 适合你 |
| "奖励一下自己" | 消费伪装成投资（§4 原话） |
| "就差这一件就完美了" | 永远"差一件"，gear optimization 无限延伸 |
| "别人穿好看" | 别人的体型/风格/场景 ≠ 你的 |

---

## 换季流程（每年 2 次：4 月 + 10 月）

1. **清点**：所有单品摊开，对照 [[Capsule-Wardrobe]] 清单
2. **淘汰**：过去一季没穿过的 → 为什么？不合身/不喜欢/不搭 → 淘汰
3. **修补**：需要修的送裁缝（扣子、裤长、袖口）
4. **缺口**：对照下一季场景需求，列采购清单（过决策框架后再买）
5. **收纳**：当季不穿的收起来，衣橱只放当季

---

## 保养规则

| 单品 | 保养 | 频率 |
|------|------|------|
| 羊毛裤/blazer | 穿后挂好通风，减少干洗 | 穿 3-5 次后干洗 |
| Merino 针织 | 手洗或羊毛程序，平晾 | 穿 2-3 次后洗 |
| 衬衫 | 机洗冷水，挂晾 | 每次穿后洗 |
| 素 T | 机洗冷水，翻面洗 | 每次穿后洗 |
| 皮鞋 | 鞋楦 + 定期上油 | 每月一次保养 |
| 小白鞋 | 脏了及时擦 | 随时 |

### 基础设施

- [ ] 好衣架（木质或丝绒，不用铁丝衣架）
- [ ] 鞋楦（cedar wood 最佳）
- [ ] 羊毛洗涤液
- [ ] 鞋油 + 鞋刷
