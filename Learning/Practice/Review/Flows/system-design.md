# 系统设计练习与复习流程

## 练习

使用 `.agents/skills/sysd-solve/SKILL.md` 的引导设计与方案审核流程。新题按需求、实体、接口、数据流、架构和深入讨论推进。继续已有 session 时，按其恢复规则核对 progress 和设计图，再从确认的进度开始。

## Review

1. 展示题目与约定的约束，让用户从空白方案开始。可用 45 分钟作为整题模拟的起点，由用户自行计时或按本轮范围调整。旧方案、图和历次决策在本轮作答结束后查看。
2. 让用户按需要澄清需求，推导接口、数据流和架构，解释一个关键决策的取舍。采用 `Learning/Practice/System-Design/AGENTS.md` 的 Delivery Framework 帮助组织完整作答。用户请求提示时记录帮助的内容，优先让用户继续推导。

## 评价与交接

收到本轮方案后，参考 `sysd-solve` 的方案审核标准检查需求覆盖、规模假设、主要请求路径和关键取舍。根据题目选择相关的故障、一致性或成本问题，指出具体受影响的需求或路径。

用本次证据提出一个回顾问题，将实际方案、图或可定位的引用、观察和结果交给通用流程。独立完成本轮约定范围并能说明关键决策记 `independent`，借助实质提示达成相同目标记 `assisted`，结束时仍缺少约定范围内的关键部分记 `incomplete`。

新建或续写原系统设计 Solution、Pattern 与 Log 由 `sysd-solve` 处理。
