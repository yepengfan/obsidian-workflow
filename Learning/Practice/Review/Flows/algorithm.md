# 算法重练流程

1. 展示题意、约束和公开样例。请用户从空白开始写代码并自行计时，默认 30 分钟，可在开练前调整。用户完成或到时后，提交当前代码、已跑的测试和实际用时。
2. 作答中只澄清题意与约束。用户请求提示时，按 `algo-solve` 的提示原则给必要的帮助，并记录提示及其对本次作答的影响。历次代码、卡点、题目复习重点和回顾问题在提交后查看。
3. 依据 `Learning/Practice/Algorithm/AGENTS.md` 和 `.agents/skills/algo-solve/SKILL.md` 的代码审核部分，检查正确性、边界、时间和空间复杂度。发现错误时给具体输入和相关代码位置。分别记录观察到的识别、工具选择和实现问题。只收到代码时，将未观察到的推导留空。
4. 用本次证据提出一个回顾问题，将实际提交的代码或可定位的引用、观察和结果交给通用流程。限时独立通过审核记 `independent`，得到实质提示后在时限内通过记 `assisted`，到时仍未通过或用户结束未完成尝试记 `incomplete`。题意澄清本身不计为提示。

Pattern 卡和算法日记的沉淀由原 `algo-solve` 流程处理。
