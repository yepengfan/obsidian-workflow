# 痛苦记录是自我改进的原材料

痛苦+反思=进步，但反思不应在痛苦发生的当下进行——当时很难保持头脑清醒。正确的做法是：在经历痛苦时先记录下来（日记是最佳载体），等情绪平复后再分析造成痛苦的根本原因，然后制定改进方案。这构成了一个完整的个人进化循环：记录痛苦 -> 分析根因 -> 制定方案 -> 执行改进。写日记因此不仅是情感宣泄，更是一个系统化的自我诊断工具。
