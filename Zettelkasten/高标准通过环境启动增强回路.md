# 高标准通过环境启动增强回路

卓越的结果几乎总是由有着高于平均标准的人取得的。标准会变成习惯，习惯会变成结果。从系统的角度看，这是一个增强回路：选择高标准的环境 -> 环境提升自身标准 -> 更高标准带来更好结果 -> 更好结果打开更好环境的大门。

关键洞察是：人可以选择环境，环境也可以改造人。一开始选择一个好的环境反而变得异常重要，因为它是启动整个增强回路的触发点。普通标准只能带来普通结果——如果起点就是平均水平，回路只会强化平庸。
