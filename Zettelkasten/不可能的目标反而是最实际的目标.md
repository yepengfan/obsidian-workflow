# 不可能的目标反而是最实际的目标

制定一个看似不可能的目标，并非自欺欺人，而是一种强大的筛选工具。当目标足够大，大到现有路径显然无法抵达时，大脑被迫放弃渐进式改良，转而重新审视整个方法论。这时候，什么管用、什么不管用会立刻变得清晰——因为渐进式的微调根本不在选项之内。

二倍目标的危险在于：它让你觉得「再努力一点就够了」，于是你沿用旧方法、加大投入，结果是更忙而非更好。十倍目标则逼你只保留最关键的少数路径，砍掉一切干扰。看似不切实际的目标，恰恰因为排除了无效选项，反而成了最踏实的目标。
