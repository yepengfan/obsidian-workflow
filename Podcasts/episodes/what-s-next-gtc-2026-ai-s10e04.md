# GTC 2026：AI的下一个战场不是模型，而是「推理系统」| S10E04

## Summary

> [!abstract]
> GTC 2026现场采访推理优化公司Eigen，深入解析Agent爆发下GPU/TPU/LPU架构差异与推理层三层优化体系，揭示AI基础设施从训练向推理转移的行业拐点。
>
> Live from GTC 2026, an interview with inference startup Eigen reveals how the agent explosion is shifting AI infrastructure focus from training to inference optimization across GPU, TPU, and LPU architectures.

## Key Takeaways

- 🔥 Agent 爆发是今年 GTC 最大主题：token 消耗量比传统 chatbot 高 1-2 个数量级，OpenClaw 跑一晚上消耗的 token 相当于人类用一个月
- 😎 黄仁勋今年状态最放松——不再需要 pitch AI ROI，AI 已成行业共识，媒体 Q&A 从白名单制变为 100+ 家全球媒体开放提问
- 🧩 NVIDIA 收购 GROQ（LPU）的战略逻辑：GPU 擅长 prefilling（并行计算），LPU 擅长 decoding（sequential 生成），两者组合是长 sequence 推理的最优解
- ⚙️ 推理优化分三层：底层 CUDA kernel 算子优化（GEMM）、中间层模型效率（Quantization IP4/IP8、Sparsity、Speculative Decoding、Expert Pruning）、上层 KVCache-aware Routing 调度
- 💰 Subscription 模式不适合 AI 产品——每次调用都在烧钱，power user 轻易用穿额度（如 Windsurf 事件），行业正从 subscription 向 per-task/usage-based 定价震荡过渡
- 🏭 预训练已高度集中到头部几家（OpenAI、Anthropic、Google、Meta 等），中小厂因 GPU 成本（10万张卡量级）已退出模型训练赛道
- 🔮 行业最大非共识：开源模型能否追上闭源模型？若开源模型达到 turning point 成为 commodity，一年内将渗透到日常生活各种 use case
- 📊 TPU 性能与 B200 持平但价格仅一半，然而零生态是致命短板——只服务少数大客户（Anthropic 等），无法像 CUDA 生态那样广泛推广

## Zettel Candidates

> [!tip] 可转化为 Zettel 的观点
> - GPU 擅长并行 prefilling，LPU 擅长 sequential decoding——未来最优推理架构是两者的组合而非替代，这解释了 NVIDIA 收购 GROQ 的底层逻辑
> - Agent 时代的 token 消耗量是人类消耗量的 100 倍以上，这意味着推理成本而非训练成本将成为 AI 商业化的核心瓶颈
> - SaaS 时代的 subscription 定价模型与 AI 按调用计费的成本结构存在根本矛盾——人们接受律师按小时收费，却不接受 AI agent 按 task 收费
