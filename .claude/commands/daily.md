Create a daily note for today in the `Thoughts/` folder.

File name format: `YYYY-MM-DD.md`

Include this frontmatter:
```
---
date: <today's date>
tags: daily
---
```

Then add these sections:
- `## Highlights` — leave empty for me to fill in
- `## Tasks` — leave empty
- `## Notes` — leave empty

After creating the note, scan my recent notes (last 7 days) and add a `## Recent Context` section at the bottom with wikilinks to recently modified notes that might be relevant. Do NOT include notes from WeRead/.
