## Overview

穿搭视觉杠杆技能 — 简约高智感风格，一次性知识构建。目标：≤30 件胶囊衣橱覆盖全场景。

## 架构

- **00_plan.md**: 总计划（阶段路线图 + 配色盘 + 面料 + 采购地图 + 书单）
- **Capsule-Wardrobe.md**: 胶囊衣橱清单 + 购物决策框架
- **Styling-Formulas.md**: 场景搭配公式速查
- **Wardrobe-Audit.md**: 体型数据 + 衣橱审计模板
- **Maintenance-Rules.md**: 防 spending risk 维护机制

## Quick Start

1. 填写 `Wardrobe-Audit.md`（量体 + 拍照清点现有衣橱）
2. 对照 `Capsule-Wardrobe.md` 列采购清单
3. 用 `Styling-Formulas.md` 组搭配
4. 进入维护模式后按 `Maintenance-Rules.md` 运行
