## Highlights
* If you put agent development on a line, raw code with no abstractions sits on the far left. You're calling APIs directly,
* Agent frameworks sit in the middle.
* The framework has opinions about how things should connect, but it's modular. You can swap components.
* Agent harnesses sit on the far right.
* All of that is decided for you.
* A harness doesn't give you building blocks. It gives you a complete system.
* Frameworks are for builders. Harnesses are for users.
* LangChain actually distinguishes between three layers in their own stack.
* LangChain (the original library) is the framework.
* LangGraph is what they call the "agent runtime,"
* Deep Agents is the harness that sits on top of both.
