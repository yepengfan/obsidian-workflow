# Phase 3 — Assemble & Write Reports

You receive a JSON payload via stdin containing scored articles and their bilingual summaries. Your job is to assemble Obsidian markdown reports and write them using the **Write** tool.

**Task**: Write exactly 3 files — a Chinese report, an English report, and a Dashboard. No other output needed.

## Input Format

```json
{
  "date": "YYYY-MM-DD",
  "vault_root": "/path/to/vault",
  "stats": { "sources_total": N, "feeds_ok": N, "articles_fetched": N, "articles_after_dedup": N },
  "articles": [
    {
      "rank": 1,
      "title": "...",
      "link": "https://...",
      "pub_date": "ISO-8601",
      "source_name": "...",
      "category": "ai-ml",
      "keywords": ["kw1", "kw2"],
      "title_zh": "中文标题",
      "summary_zh": "...",
      "reason_zh": "...",
      "summary_en": "...",
      "reason_en": "..."
    }
  ],
  "trend_zh": "...",
  "trend_en": "..."
}
```

## Emoji Mappings

### Category
- `ai-ml` → 🤖 AI / ML
- `security` → 🔒 Security
- `engineering` → ⚙️ Engineering
- `tools` → 🛠️ Tools
- `opinion` → 💬 Opinion
- `other` → 📌 Other

### Rank
- #1 → 🥇, #2 → 🥈, #3 → 🥉
- #4+ → `#4`, `#5`, ... `#15`

### Relative Time
Calculate from `pub_date` relative to the `date` field (assume end of day):
- < 1 hour → "just now"
- < 24 hours → "{hours}h ago"
- >= 24 hours → "{days}d ago"

## Rules

1. Use **absolute paths** with the `vault_root` for the Write tool.
2. Every article MUST have its callout block — do not skip any.
3. Preserve the exact callout format (`> [!tip]` blocks) — Obsidian depends on this syntax.
4. **Blank line between each callout block** — required for Obsidian to render them separately.
5. Do not create any files other than the 3 specified above.
6. After writing all files, output a brief one-line confirmation to stdout.
